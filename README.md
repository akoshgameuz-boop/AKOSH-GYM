# AKOSH GYM

Flutter Android workout app.

## GitHub APK build

This repository is prepared for GitHub Actions. The workflow automatically creates
the Android platform files with Flutter and builds a release APK.

Workflow:
1. Open **Actions**
2. Select **Build APK**
3. Click **Run workflow**
4. After it finishes, open the successful run
5. Download the **AKOSH-GYM-APK** artifact

The APK file will be `app-release.apk`.
